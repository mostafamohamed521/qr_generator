GET /api/v1/me/ Get account info

Returns info about the authenticated key owner.

curl /api/v1/me/ -H "Authorization: Bearer qrf_your_key"
{"ok":true,"user":{"id":1,"email":"you@example.com","qr_total":42,"dyn_total":3}}
POST /api/v1/generate/ Generate a QR code image
Request Body (JSON)
typestringRequired. One of: url, text, contact, wifi, sms, email, phone, location
urlstringURL to encode (when type=url)
textstringText content (when type=text)
qr_colorstringHex color, default #000000
bg_colorstringHex or "transparent", default #ffffff
sizeinteger100–1000 px, default 300
stylestring"square" or "rounded"
labelstringOptional label saved in history
curl -X POST /api/v1/generate/ \ -H "Authorization: Bearer qrf_your_key" \ -H "Content-Type: application/json" \ -d '{"type":"url","url":"https://example.com","size":300}'
Response
{ "ok": true, "id": 42, "content": "https://example.com", "image": "data:image/png;base64,iVBOR..." }
GET /api/v1/qrcodes/ List QR codes
pageintegerPage number, default 1
per_pageintegerItems per page, max 50, default 20
qstringSearch in label/content
typestringFilter by QR type
curl /api/v1/qrcodes/?page=1&type=url \ -H "Authorization: Bearer qrf_your_key"
{ "ok": true, "total": 42, "page": 1, "pages": 3, "items": [{ "id": 1, "type": "url", "label": "...", ... }] }
GET /api/v1/qrcodes/<id>/ Get single QR code
curl /api/v1/qrcodes/42/ -H "Authorization: Bearer qrf_your_key"
{ "ok": true, "item": { "id": 42, "type": "url", "image": "data:...", ... } }
POST /api/v1/qrcodes/<id>/delete/ Delete a QR code
curl -X POST /api/v1/qrcodes/42/delete/ -H "Authorization: Bearer qrf_your_key"
{ "ok": true }
GET /api/v1/dynamic/ List dynamic links
curl /api/v1/dynamic/ -H "Authorization: Bearer qrf_your_key"
{ "ok": true, "links": [{ "id": 1, "short_code": "jHqq2jtc", "target_url": "...", "scan_count": 5 }] }
POST /api/v1/dynamic/create/ Create dynamic link
curl -X POST /api/v1/dynamic/create/ \ -H "Authorization: Bearer qrf_your_key" \ -d '{"target_url":"https://example.com","label":"My Campaign"}'
{ "ok": true, "link": { "id": 1, "short_code": "abc12345", "redirect_url": "https://yoursite.com/r/abc12345/" } }
POST /api/v1/dynamic/<id>/update/ Update destination URL
curl -X POST /api/v1/dynamic/1/update/ \ -H "Authorization: Bearer qrf_your_key" \ -d '{"target_url":"https://new-destination.com","is_active":true}'
{ "ok": true, "target_url": "https://new-destination.com", "is_active": true }
